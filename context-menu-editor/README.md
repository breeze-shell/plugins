# 右键菜单编辑器

breeze-shell 的可视化右键菜单编辑器：把真实弹出的右键菜单采集下来，用拖拽的方式重排、分组、改名、换图标、隐藏，
再按 **菜单类型** 分别保存成规则，每次菜单弹出时自动套用。

TypeScript + React（breeze 的内置渲染器）+ Fluent Design，构建产物是仓库根目录的单文件插件 `context-menu-editor.js`。

![编辑器窗口](docs/window-preview.png)

## 功能

| 能力 | 说明 |
| --- | --- |
| 所见即所得 | 中间那列就是你这条菜单的当前样子：规则行 + 还没被规则覆盖的原生项（灰色，带「原生」标记）按真实菜单的顺序混排；动一下灰色行，它就变成规则 |
| 拖拽排序 | 抓住任意一行拖动（有移动阈值，点一下不会误拖），行与行之间显示插入线 |
| 分组 | 两种布局：**分组**（收进子菜单）与**横排**（子项排成一行按钮）；横排里放不下分组，这种落点会被拒绝并说明原因 |
| 拖进 / 拖出分组 | 拖到分组标题的中线上放入分组（放进去会自动展开）；拖到「移出规则」横条把项还原成原生项 |
| 新建分组 | 工具栏「分组 / 横排」；也可以把选中项一键收纳进新分组 |
| 重命名 | 行上的铅笔、或**双击整行**进入原地改名，回车保存 / Esc 取消；右侧检查器的显示名称也能改。留空则沿用原生名称（含本地化名称） |
| 赋图标 | 38 个内置 Fluent 图标 + 自定义 SVG + 「原生图标」/「无图标」；图标颜色跟随菜单的深浅色主题 |
| 隐藏 / 显示 | 单行眼睛按钮或检查器开关；隐藏项在编辑器里半透明显示，方便随时恢复。**原生行没有"删除"，只有"隐藏"** |
| 禁用 | 置灰不可点（原生已禁用的项始终禁用） |
| 分隔线 | 任意位置插入（分组里也行），自动清理开头/结尾/连续的分隔线；会被清理的行上直接标出来 |
| 自定义命令 | 新建菜单项：运行/打开路径或复制文本。参数里的 `%PATH%` 换成选中项（没有选中时是当前文件夹），`%FOLDER%` 换成当前文件夹，含空格的路径自动加引号 |
| 按类型生效 | 选中文件 / 文件夹空白处 / 桌面 / 任务栏 / 其他程序，各存一份规则 |
| 其他程序过滤 | 「其他程序」可以按进程名与窗口标题过滤 |
| 未列项策略 | 未纳入规则的原生项（含原生分隔线）：保持原位置（默认）/ 挪到末尾 / 隐藏 |
| 检查器 | 表单区可滚动，底部操作条固定：上移/下移、移到开头/移到末尾、收纳成分组/解散分组/移出分组、复制/删除 |
| 画布上的警示 | 空分组、会被省略的分隔线、被忽略的横排内分组、匹配不到的原生项，都会在那一行上直接标出来 |
| 快捷键 | Ctrl+Z / Ctrl+Y 撤销重做，Ctrl+D 复制，Ctrl+Delete 删除，Ctrl+↑↓ 移动位置，Alt+↑↓ 选择上下行，Enter 改名，Esc 取消选中；在输入框里打字时不触发 |
| 撤销重做 | 40 步历史，存的是**整份规则**（含启用开关、未列项策略、进程/标题过滤），跨菜单类型；同一个输入框的连续输入算一步 |
| 全部纳入规则 | 一键把未纳入的原生项变成规则行，已有规则保持不动 |

术语只有两个：**规则项**（写进规则的项）与**未纳入的原生项**（菜单里有、规则没提到的项），计数单位都是「项」。

## 使用

1. 右键打开一次要编辑的菜单（例如在文件上右键）。这一步会被插件采集下来。
2. 菜单里点 **右键菜单编辑器 ▸ 编辑这个菜单…**；也可以在 breeze 设置的插件列表里打开本插件的菜单，选 **右键菜单编辑器…**，再从左侧选类型。
3. 中间已经列出这条菜单的完整内容：直接拖、改名、换图标、分组就行；灰色的原生项第一次动它时会自动变成规则。
4. 打开右上角的规则开关（或菜单里的 **启用该类型的规则**）。
5. 之后再打开这个菜单，就会按规则呈现。

规则只描述「怎么改」，不改动原生菜单本身；关掉开关即可恢复原样。菜单里的 **把未纳入的原生项收进规则** 只补上还没被规则覆盖的项。

原生项按 `name_resid`（资源串 ID）> `origin_name`（原始文本）> `name`（显示文本）生成匹配键，重复的名字按出现次序追加 `#1` / `#2`；
检查器里的「匹配信息」会显示 `wID` / 资源 ID / 原始文本 / 快捷键，方便排查规则没生效的原因。

## 目录

```
context-menu-editor/
├─ build.mjs          esbuild 构建脚本, 产出仓库根目录的 context-menu-editor.js
├─ src/
│  ├─ index.tsx       插件入口: 菜单监听、采集、应用规则、菜单里的入口
│  ├─ store.ts        设置的唯一持有者: 合并编辑器上报的规则、推送变化、防抖写盘
│  ├─ plan.ts         采集 / 匹配 / 计划 / 重建 (与 UI 无关, 可单测)
│  ├─ model.ts        规则树的纯函数操作 (移动/分组/复制)
│  ├─ history.ts      撤销重做栈
│  ├─ shortcuts.ts    快捷键映射
│  ├─ settings.ts     配置读写与严格校验 (手改坏的 config.json 也能兜住)
│  ├─ types.ts        规则与设置的模型类型
│  ├─ app.tsx         编辑器窗口 (三栏 + 拖拽 + 检查器 + 图标选择)
│  ├─ ui.tsx          Fluent Design 组件集
│  ├─ theme.ts        主题 token 与内置图标
│  ├─ window.ts       插件窗口生命周期
│  └─ i18n.ts         zh-CN / en-US
├─ test/              逻辑测试 (node + mshell stub) 与沙箱 e2e 脚本
└─ docs/              截图
```

## 开发

```powershell
cd context-menu-editor
npm install
npm run typecheck      # tsc --noEmit
npm run build          # 产出 ../context-menu-editor.js
npm test               # 逻辑测试 (无 shell, 用 mshell stub)
npm run check          # 以上三步
```
